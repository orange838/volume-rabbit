# 早读萝卜

用麦克风音量驱动兔子拔萝卜的 [Class Widgets 2](https://github.com/Class-Widgets/Class-Widgets) 插件。

声音够大，兔子就开拔；声音不够，兔子就停下。适合早读、朗读课，也适合用「安静模式」管自习纪律。

## 两种模式

| 模式 | 判定 | 速度 |
|---|---|---|
| 早读模式 | 音量 ≥ 阈值才拔 | 越响越快（封顶 2.2 倍） |
| 安静模式 | 音量 ≤ 阈值才拔 | 达标后匀速；一吵就停 |

阈值是 **底噪 + 固定 dB**（早读模式默认高 10 dB），底噪由程序自动跟踪：往下跟得快，往上则只在「贴着底噪」时才慢慢爬，人一说话就冻住，所以越读阈值不会跟着往上跑。换教室、换麦克风不用重调，设置页和大屏上的灵敏度滑块是 ±18 dB 微调（两种模式都是「往左更容易达标」）。

判定用的是**声音包络**（一响就抬起来、之后按 12 dB/秒回落），不是某一瞬间的电平，所以朗读时音节之间的空档不会打断拔萝卜。

## 安装

### 从插件广场

Class Widgets 2 → 设置 → 插件 → 插件广场，搜索「早读萝卜」安装。

### 手动安装

把插件目录放到数据目录下的 `plugins\org.cslblog.volumerabbit\`：

- 便携版：`<安装目录>\data\plugins\`
- 普通安装：`%LOCALAPPDATA%\Class_Widgets_2\plugins\`

然后在设置 → 插件里启用「早读萝卜」。

## 用法

设置页 →「打开大窗口」，或者直接按大窗口里的「开始」。
装了插件之后，**快捷面板**的「快捷方式」里会多一个「早读萝卜」，点一下就能直接打开大窗口，不用先进设置页。

- 兔子数量 N = N 个坑位，排队轮流：第 1 只拔完第 1 根后萝卜留在坑里，轮到第 2 只……N 只全拔完 → 停 2 秒 → 整排重置。
- 音量掉下去先停 1 秒（迟滞，换气不算失败），仍不达标才开始回落，回落速度默认是前进的 30%，而且**只落 2 秒就停**（满速下约 7%）。设置页的「回落速度」可以调 0%~100%，调到 0% 就是拔出来的不会再掉。
- 再次达标立刻继续往上拔。

### 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 开始 / 暂停 |
| `F` | 全屏 |
| `Esc` | 全屏时先退出全屏，再按一次关闭窗口 |

### 大屏上的电平条

左下角面板：彩色填充是当前电平，深棕竖线是当前阈值，下面一行是「电平 / 底噪 / 阈值」数值，最底下是可拖动的灵敏度滑条（±18 dB）。拔得太慢就往左拖，太容易就往右拖；还是拔不动就直接拉到最左，那时阈值基本等于底噪，说话就能拔。

大屏滑条和设置页的灵敏度滑块是**同一个值**：拖哪边，另一边下次打开 / 刷新时都是新值。

## 隐私

不录音、不落盘、不联网，只在内存里每 60 ms 算一次 RMS 音量。

## 开发

```bash
pip install class-widgets-sdk

# 本地打包
cw-plugin-pack . --format cwplugin
cw-plugin-pack . --format zip

# 打 tag 后 GitHub Actions 自动打包并发布到插件广场（需配置 CWPT_TOKEN）
git tag v0.1.0
git push origin v0.1.0
```

目录结构：

```
main.py           插件入口：生命周期、配置、窗口
_vr/audio.py      QAudioSource 采集 + RMS → dBFS，失败自动重试
_vr/engine.py     拔萝卜状态机（纯 Python，无 Qt 依赖）
qml/              大窗口与设置页
```
